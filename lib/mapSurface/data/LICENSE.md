# Bundled OpenFreeMap Liberty style

`liberty-style.json` is a snapshot of the OpenFreeMap Liberty style JSON
(`https://tiles.openfreemap.org/styles/liberty`).

- Project / packaging: MIT (OpenFreeMap)
- Liberty design lineage: OSM Liberty / OSM Bright — **BSD 3-Clause** (code), **CC BY 4.0** (design)
- See: https://github.com/hyperknot/openfreemap-styles/blob/main/LICENSE.md

Bundled so the app does not fetch the style over the network. Map data remains OpenStreetMap / OpenMapTiles.
