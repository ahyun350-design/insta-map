# Glyph PBF licenses

MapLibre glyph PBFs under this directory are derived from **Noto Sans**
(Regular / Bold / Italic), served by OpenFreeMap.

- Font: [Noto Sans](https://www.google.com/get/noto/) — **SIL Open Font License 1.1**
- Source distribution: [OpenFreeMap styles LICENSE](https://github.com/hyperknot/openfreemap-styles/blob/main/LICENSE.md)

Only Latin / symbol ranges needed with `localIdeographFontFamily` (Hangul via device fonts) are bundled here. Paths are never written to localStorage or IndexedDB.
